1Estructura del grafo

¿Cuál es la estructura del grafo?

Modelo principal: grafo de estaciones G = (V, E, w)

  • V: {{ r.resumen.vertices }} estaciones. Una estación de transbordo (p. ej. Sol, con L1, L2 y L3) es un solo vértice.
  • E: {{ r.resumen.aristas }} aristas = {{ r.resumen.tramos_de_tren }} tramos de tren entre estaciones consecutivas + {{ r.resumen.pasillos_peatonales }} pasillos peatonales.
  • w: E → ℝ+, peso en tiempo (min) o distancia (km).
  • No dirigido (los trenes van en ambos sentidos), ponderado, simple (si dos líneas comparten tramo, como Chamartín – Plaza de Castilla con L1 y L10, hay una sola arista) y conexo.

Modelo auxiliar: grafo de servicios GL

Cada vértice es un par (estación, servicio): {{ r.gl_vertices }} vértices y {{ r.gl_aristas }} aristas, de las que {{ r.gl_transbordos }} son de transbordo. Un camino en GL sabe en qué línea va el viajero, lo que permite contar y minimizar transbordos (imposible en G). La L10 se divide en los servicios 10A y 10B porque en Tres Olivos hay que cambiar de tren.

Comparación de algoritmos (en vivo)

Algoritmos implementados

BFS · menos paradas · O(V + E)

Explora por niveles con una cola FIFO. En un grafo no ponderado, el primer camino que llega al destino es el de menos aristas.

Dijkstra · menor tiempo · O((V + E) log V)

Cola de prioridad (heap): siempre expande el vértice con menor distancia acumulada g(n). Es correcto porque los pesos son positivos.

A* · búsqueda informada (IA)

Prioridad f(n) = g(n) + h(n), con h(n) = distancia en línea recta / {{ constantes.velocidad|int }} km/h. La heurística es admisible (nunca sobreestima, por la desigualdad triangular), así que la ruta sigue siendo óptima.

Para menos transbordos, cada transbordo pesa 1000 en GL. Eso equivale a un orden lexicográfico: primero minimiza transbordos y luego tiempo. El origen y el destino se conectan a todos sus servicios mediante vértices virtuales de costo 0.

{{ tablas.ejemplos_rutas }}
Validación: en {{ r.validacion.pares }} pares aleatorios, Dijkstra propio coincide con NetworkX en {{ r.validacion.dijkstra }}/{{ r.validacion.pares }}, A* en {{ r.validacion.a_estrella }}/{{ r.validacion.pares }} y BFS en {{ r.validacion.bfs }}/{{ r.validacion.pares }}. A* explora en promedio {{ r.validacion.explorados_a_estrella }} nodos frente a {{ r.validacion.explorados_dijkstra }} de Dijkstra ({{ r.validacion.ahorro_a_estrella }}% menos).
Los criterios pueden dar rutas distintas: de Las Rosas a Pitis, la ruta más rápida usa 2 transbordos y la de menos transbordos tarda más. Es un problema de optimización multiobjetivo: el "mejor" camino depende de la función de peso.

4¿Qué pasa si se elimina una estación clave?

¿Qué pasa con la conectividad de la red si se elimina una estación clave (por ejemplo, un nodo de transbordo)?

Eliminar el vértice v da el subgrafo G − v. Se mide el número de componentes conexas, el tamaño de la componente gigante y la eficiencia global E = 1/(n(n−1)) Σu≠v 1/d(u, v), que vale 0 entre estaciones incomunicadas. Simulador: haz clic en estaciones del mapa para cerrarlas.

7Propiedades y teoremas

Lema del apretón de manos

Σv∈V deg(v) = 2|E| → {{ r.apreton.suma_grados }} = 2 · {{ r.resumen.aristas }} Cada arista suma 1 al grado de sus dos extremos. Corolario: el número de vértices de grado impar es par (aquí, {{ r.euler.vertices_grado_impar }}).

Caminos y circuitos eulerianos

Un grafo conexo tiene circuito euleriano si y solo si todos sus grados son pares, y camino euleriano si hay exactamente 0 o 2 vértices de grado impar. Aquí hay {{ r.euler.vertices_grado_impar }} vértices impares, así que no se pueden recorrer todos los tramos una sola vez. La solución óptima es el problema del cartero chino.

Ciclos y árbol de expansión mínima

Número ciclomático μ = |E| − |V| + c = {{ r.resumen.aristas }} − {{ r.resumen.vertices }} + 1 = {{ r.globales.numero_ciclomatico }} ciclos independientes. Kruskal encuentra el árbol con |V| − 1 = {{ r.mst.aristas_mst }} aristas ({{ r.mst.tiempo_mst_min }} min). Las {{ r.mst.aristas_redundantes }} restantes son la redundancia que ofrece rutas alternativas ({{ r.mst.porcentaje_redundancia }}% del tiempo total de vía).

Planaridad (teorema de Kuratowski)

El grafo {{ "sí" if r.globales.es_planar else "no" }} es planar: contiene una subdivisión de K5 o K3,3, así que no se puede dibujar en el plano sin cruces. En la realidad las líneas se cruzan bajo tierra, a distinto nivel. Tampoco es bipartito: tiene ciclos impares, por ejemplo {{ r.coloreo.triangulos }} triángulos como {{ r.coloreo.clique_maxima|join(" – ") }}.

9Optimización combinatoria

9.1 Problema del cartero chino: inspección de todas las vías

¿Cuál es el recorrido cerrado más corto que pasa al menos una vez por cada tramo (p. ej. un tren de inspección)? Como hay {{ r.cartero.vertices_impares }} vértices de grado impar, no existe circuito euleriano. El algoritmo de Edmonds–Johnson:

  1. Encuentra los {{ r.cartero.vertices_impares }} vértices de grado impar.
  2. Calcula las distancias mínimas entre ellos (Dijkstra) y los empareja con un emparejamiento perfecto de peso mínimo.
  3. Duplica los caminos emparejados: todos los grados quedan pares, así que el multigrafo es euleriano.
  4. Obtiene el circuito euleriano con el algoritmo de Hierholzer.
Recorrer toda la red una vez cuesta {{ r.cartero.costo_red_min }} min; el recorrido óptimo necesita repetir {{ r.cartero.duplicadas }} tramos (+{{ r.cartero.costo_extra_min }} min, un {{ r.cartero.extra_pct }}% extra), en total {{ r.cartero.costo_total_min }} min ≈ {{ r.cartero.horas }} h, en un circuito de {{ r.cartero.aristas_circuito }} tramos que sale y vuelve a Sol.

10Comunidades: zonas naturales de la red

El algoritmo de Louvain agrupa estaciones maximizando la modularidad:

Q = (1/2m) Σij [ Aij − kikj/2m ] δ(ci, cj)

Q mide cuántas aristas más hay dentro de cada grupo de las que habría al azar. Se encontraron {{ r.comunidades.numero }} comunidades con Q = {{ r.comunidades.modularidad }} (valores sobre 0.3 ya indican una estructura de comunidades clara).

Las comunidades corresponden a barrios y corredores: el sur metropolitano de la L12, el corredor este de L5/L7, el norte de la L10, etc. Sirven para planificar servicios zonales o buses de reemplazo por zona.

12Complejidad empírica de los algoritmos

Se generaron redes sintéticas parecidas al metro (planas, dispersas, con E ≈ 1.15·V) de 250 a 16 000 vértices y se midieron 60 consultas aleatorias con nuestras implementaciones (mejor de 3 repeticiones).
